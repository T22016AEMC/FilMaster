# FilMaster

半導體旋塗製程的**膜厚與固含量預測工具**：給定目標膜厚、轉速與旋塗時間，反推需要調配的光阻／塗料固含量，並可用現場實測數據校正模型。

核心公式（Meyerhofer 冪律模型）：

```
h = C · S^α · ω^(−β) · t^(−γ)
```

| 符號 | 意義 |
|---|---|
| h | 膜厚 (nm) |
| S | 固含量 (wt%) |
| ω | 主轉速 (RPM) |
| t | 旋塗時間 (s) |
| C | 比例係數（可由實測數據校正） |
| α、β、γ | 固含量、轉速、時間的指數 |

## 主要功能

- **多種材料**：EUV、ArF、KrF、BARC、SOC，以及 500 nm～20 µm 的中厚膜、超厚膜與高黏度 PI／SU-8，各有預設物理常數。
- **正算與反算**：由固含量算膜厚；由目標膜厚反推建議固含量，並依可設定的容差（±0.1%～±10%）給出固含量上下限。
- **實測數據校正**：
  - 0 點：理論預設模式
  - 1 點：單點平移校正
  - 2 點以上：對數空間最小平方法擬合 α 與 C
  - 每個實測點會記錄量測當下的轉速與時間
- **警告提示**：擬合結果不合理、無法擬合、或反算出的固含量超出 0～100 wt% 時，以警示框說明原因與程式的處理方式；R² 不適用時會標示原因。
- **材料基本值庫**：把校正結果存成自訂材料基本值，之後可載入作為新的基準並二次校正；支援 JSON 匯出與匯入（匯入時會逐筆驗證，並列出被略過的項目與原因）。
- **圖表與分析**：固含量－膜厚特性曲線、機台製程窗型與靈敏度分析、固含量對應膜厚數值表。
- **報告與匯出**：複製結構化文字報告、下載 CSV 數據點。
- **情境預設**：內建 9 個常用情境（含官方測試範例）可一鍵載入。

## 資料與隱私

自訂曲線儲存在**你自己瀏覽器的 localStorage**，不會上傳到任何伺服器。換瀏覽器或清除網站資料後就看不到，需要備份請使用「匯出備份」下載 JSON。

## 本機開發

建議使用 Node.js 24（`npm test` 使用的 jsdom 要求 Node 22.22 以上或 24.15 以上；只執行 `npm run dev` 與 `npm run build` 時 Node 20 以上即可）。

```bash
npm install     # 安裝套件
npm run dev     # 啟動開發伺服器
npm test        # 執行測試
npm run build   # 型別檢查並建置到 dist/
```

本機網址需要帶 `/FilMaster/`（Vite 的 `base` 設定）：

- 開發：<http://localhost:5173/FilMaster/>
- `npm run preview` 預覽建置結果時同樣要帶 `/FilMaster/`

其他指令：`npm run lint`（TypeScript 型別檢查）、`npm run test:watch`（監看模式測試）。

## 技術棧

React 19、Vite、TypeScript（嚴格模式）、Tailwind CSS 4、Recharts，測試使用 Vitest 與 Testing Library。部署使用 GitHub Actions 發布到 GitHub Pages（測試未通過就不會部署）。
